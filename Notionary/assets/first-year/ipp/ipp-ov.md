# Introduction to Python Programming (IPP)
---
**Python** was created by **Guido van Rossum** a Dutch programmer, it was first officially released on February 20, 1991.  
Python is a free and open source software hence, we can access the source code of Python, use and modify it to our liking.  
Python is a dynamically typed **Object oriented Programming** language with its core focus being on exceptional readability. The name **"Python"** is inspired by the BBC comedy television series Monty Python's Flying Circus, of which van Rossum was a huge fan.  

In the modern day, python is used for **Automation & Scripting**, **Data Science**, **Ai & Machine Learning** by individuals and companies worldwide. We will be using Python3, the current version of python to learn about its features and uses.
